what the inventory proved

The ground rules the call is made on

The cost is in the identifiers, not the prose. Prose is a text pass. Label objects, two skill directories (= the slash commands), the schema artifact id and its assertions/** record directory, eval fixture filenames, and OpenSpec requirement-heading keys are migrations.
A label rename is rename-in-place. The label keeps its id; every attached issue follows, closed ones included. The whole live tracker migration is three issues — #12 (closed), #17, #19 — and three of the five candidate labels have never been applied, unit among them.
But the tracker migration is several operations. The strings are hard-coded in bin/ — flywheel-batch --kind, the compose predicate at bin/flywheel:373 (fails silently), flywheel-setup, flywheel-migrate. And ensure_labels is create-if-missing: a tracker migrated ahead of the code silently regrows the old label. Code first, then labels.
Renaming the schema artifact id breaks every consuming repo. install-schemas copies by plain directory name, never consults version:; there is no side-by-side path (#27). Renaming assertions/** is a breaking rev with no migration story.
No gate catches a half-landed rename. Nothing in CI greps any of the four words; the evals gate has never fired (#23). Whatever wins, the landing pass polices itself.
Tracker history keeps the old words forever. labeled timeline events carry id-less snapshots. “Nothing reads as a survivor” is achievable in the tree, not in tracker history — worth accepting out loud.
